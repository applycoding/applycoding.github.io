I have been shipping software since 2011, mostly for startups, as an engineer and project manager. Since 2022 at Vision One Tech (USA, remote) I have built production LLM systems (RAG, agents with tool use, evaluation, guardrails and monitoring) and led the software stack for Titan, a humanoid robot with 25 actuators on NVIDIA Jetson AGX Thor and ROS2, which reached the finals of the Army xTech Humanoid competition. I also build autonomous drone software (Raspberry Pi and Jetson Orin companion computers with web and Flutter mission control), Flutter apps for iOS and Android, and full-stack products on Next.js and Cloudflare Workers.
